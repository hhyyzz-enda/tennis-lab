# 图片来源与许可说明

本文档用于说明项目中当前使用的外部图片来源、使用位置和常见许可注意事项，便于课程答辩、项目交付和后续素材替换时快速核对。

## 1. 说明范围

- 本文档主要覆盖项目内业务代码主动引用的外部图片资源。
- 当前重点覆盖课程封面图片来源：
  - `src/mock/tennisAiCourses.json`
  - `src/mock/premiumCourses.json`
- 另补充记录资源站页面使用的网站图标来源：
  - `src/views/TennisResourcesView.vue`
- 不包含以下内容：
  - 本地静态图片资源，如 `src/assets/**`
  - 视频链接，如 `Bilibili`
  - 字体资源，如 `Google Fonts`
  - 后端 API 地址

## 5. 资源站图标来源

文件：`src/views/TennisResourcesView.vue`

该页面为了给外部站点展示 favicon，会按候选顺序拼接两类外部地址：

- `https://icons.duckduckgo.com/ip3/${host}.ico`
- `https://www.google.com/s2/favicons?sz=128&domain_url=${encodeURIComponent(url)}`

说明：

- 这两类资源用于展示外部网站图标，不属于课程封面图。
- 它们是运行时动态生成的图标请求，而不是固定写死的单张课程素材。

## 6. 许可说明

### 6.1 Unsplash

官方许可页：

- `https://unsplash.com/license`

可理解为：

- 可免费下载和使用
- 可用于个人和商业项目
- 允许裁剪、缩放、加字、改色等常规二次处理
- 一般不强制署名，但署名是被鼓励的

需要注意：

- 不能几乎不做修改就把图片本身作为商品出售
- 不能批量收集图片后做成类似图库站、壁纸站或竞品服务
- 如果图片中含有人物、品牌、商标、建筑物等，商业宣传时仍应注意人格权、商标权和场景使用风险

### 6.2 Pexels

官方许可与条款页：

- `https://www.pexels.com/license/`
- `https://help.pexels.com/hc/en-us/articles/900005880463-What-are-the-Terms-and-Conditions`

可理解为：

- 可免费用于个人和商业项目
- 一般不强制署名
- 允许常规二次编辑和页面展示使用

需要注意：

- 不能原样单独售卖或分发图片
- 不能批量汇编素材形成类似竞品服务
- 不能让图片中的人物、品牌或标识看起来像是在为产品背书
- 若图片中出现商标、logo 或明确品牌元素，商业使用要更谨慎

## 7. 对本项目的适用判断

以当前项目的使用方式来看，以下场景通常是合理的：

- 作为课程卡片封面展示
- 作为网站内容配图
- 对图片做前端尺寸裁剪、遮罩、模糊、加文字等展示性处理

以下做法不建议直接采用：

- 原图几乎不改直接二次售卖
- 批量抓取外部图库图片搭建新的图片素材站
- 将含人物或品牌元素的图片用于带有代言意味的商业宣传

## 8. 建议的项目表述

如果需要在答辩材料、README 或交付文档中说明图片来源，建议使用以下说法：

> 项目中的部分课程封面图片来自 Unsplash 与 Pexels，依据其平台许可免费使用；资源站图标通过 DuckDuckGo Icons 和 Google S2 Favicon 在运行时动态拉取。

不建议写成：

- “所有图片均为开源图片”
- “所有图片均为无任何限制可商用素材”

更准确的表述应为：

- “免费授权图库图片”
- “依据平台许可可用于项目展示”

## 9. 后续维护建议

- 新增外部图片时，优先记录来源平台、原始页面和作者名
- 若图片用于答辩展示或对外发布页面，建议保留一份素材来源备查表
- 若后续改为通过 API 拉取图片，需要额外核对 API 条款是否要求署名、跳转或下载统计
- 若项目将来用于正式商业发布，建议对带人物或品牌元素的图片做一次集中复核
