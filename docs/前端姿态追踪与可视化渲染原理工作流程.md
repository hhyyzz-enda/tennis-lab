本系统基于 **Vue 3 + Vite** 构建，使用开源姿态识别框架 **MediaPipe（Vision Tasks，Pose Landmarker）**，在纯浏览器端（无需后端服务端推理）完成视频关键点提取、动作分析与可视化。

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                        前端浏览器（单页 SPA）                                │

│  ┌──────────────┐    ┌─────────────────┐    ┌───────────────────────┐    │
│  │  用户上传视频 │───▶│ MediaPipe WASM  │───▶│  髋/胸/肩/肘 关键点 │    │
│  └──────────────┘    │   PoseLandmarker  │    │  + 角度/角速度/峰值提取  │    │
│                    └─────────────────┘    └───────────┘                     │
│                                                                 │           │
│                    ┌────────────────────────────────────────┐                    │
│                    │  Canvas 叠加层 绘制骨架/高亮关节点 / 标准模板对比  │                    │
│                    └────────────────────────────────────────┘                    │
│                                │                                         │
│                    ┌────────────────────────────────────────┐                    │
```

## 三、髋 / 胸 / 肩 / 肘 核心点索引

MediaPipe Pose Landmarker 输出 33 个归一化（归一化（0~1 坐标，本系统只取以下 8 个原始索引点，再合成 4 个核心分析点：

```
原始 MediaPipe Pose 原始索引：
  11 = 左肩  leftShoulder
  12 = 右肩  rightShoulder
  13 = 左肘  leftElbow
  14 = 右肘  rightElbow
  15 = 左手腕 leftWrist
  16 = 右手腕 rightWrist
  23 = 左髋  leftHip
  24 = 右髋  rightHip
```

核心 4 个分析点定义（其中 **`髋（hip）、胸（chest）、肩（shoulder）、肘（elbow）`

```js
// 见 [OVERLAY_INDEX](file:///c:/Users/hhyyz/Desktop/volleyball/tennis-lab/src/components/LocalPoseAnalysis.vue#L361-L370)
{
  shoulder:  根据持拍手侧（left/rightShoulder（左/右肩中点，即同侧肩肩肩肩肩肩
  elbow:  持拍手侧肘（left/rightElbow
  hip:    持拍手侧髋（left/rightHip
  chest:  肩中点 ↔ 髋中点 连线的 30% 处（插值中点）
}
```

> `chest 点是一个**合成点**，它不是 MediaPipe 原关键点，由肩中点与髋中点按 0.3 的比例加权得到，用以代表躯干传导点。

## 四、模型加载与初始化流程

### 4.1 资源加载策略（兼容 dev/build）

```js
// 见 [resolvePublicAssetUrl](file:///c:/Users/hhyyz/Desktop/volleyball/tennis-lab/src/components/LocalPoseAnalysis.vue#L354-L358)
const appBaseUrl = new URL(import.meta.env.BASE_URL, window.location.origin)
```

## 五、关键帧采集与追踪（detectForVideo）

### 5.1 抽帧策略

```js
// 见 [collectFrames](file:///c:/Users/hhyyz/Desktop/volleyball/tennis-lab/src/components/LocalPoseAnalysis.vue#L1087-L1106)
- 时长 > 8s → 12 FPS；≤ 8s → 15 FPS
- step = 1 / fps，按固定时间步 seek 视频到指定时刻
- 对每个时刻：landmarker.detectForVideo(videoEl, time*1000)
```

**关键点说明：
- **不是实时摄像头流，而是**视频离线逐帧采样后再做后分析**；
- 用户在视频上拖动播放 → 由 `previewTime` 决定取对应帧的 landmarks；
- landmarks 的坐标 `x, y` 已归一化（**相对视频宽高比。

### 6.3 阶段判定

```js
// 见 [getPhaseKey](file:///c:/Users/hhyyz/Desktop/volleyball/tennis-lab/src/utils/poseAnalysis.js#L198-L202)
```

### 7.2 绘制触发时机

### 7.3 drawOverlay 绘制流水线

```
1. resizeOverlayCanvas() → 对齐视频 DOM 实际尺寸 × DPR

3. getFrameByTime(previewTime) → 找到离当前时刻最近的采样帧
4. 取 landmarks → 算出 shoulder / elbow / hip / chest 4 点
5. drawLine()  画骨架线
6. drawPoint() 画 4 个关节圆点（含高亮发光）
```

### 7.4 骨架线（白色半透明连接线）

```js
画 6 条线：

├─ 左髋 ↔ 右髋
```

visibility < 0.2 → **不画（避免抖动垃圾连线。

### 7.5 关节圆点（4 色高亮标记）

```js
// 见 [drawPoint](file:///c:/Users/hhyyz/Desktop/volleyball/tennis-lab/src/components/LocalPoseAnalysis.vue#L863-L895)

每个关节配置独立色值：
  hip:    髋 = #f2b233 (金橙色)
  chest:  胸 = #2b5cb8 (蓝)
  shoulder: 肩 = #49a65a (绿)
  elbow: 肘 = #d9534f (红)

绘制三层：
 ① 若当前处于该关节主导阶段：外层大发光圈（glow，#color + 33 透明度，半径 2.2x）
 ② 实心圆点（radius 6~8px（主导阶段半径 8px，普通 6px）
 ③ 白色描边 2px
 ④ 中文标签（髋/胸/肩/肘 或 H/C/S/E 英文
```

**当前主导关节 = 当前阶段 key：
- prepare 阶段默认高亮 shoulder
- hip 阶段 → 髋点加大+发光
- chest 阶段 → 胸点加大+发光
- ...依此类推

### 7.6 DPR 高清处理

```js
const ratio = window.devicePixelRatio || 1
canvas.width  = rect.width  * ratio    // buffer 像素
canvas.height = rect.height * ratio
canvas.style.width  = rect.width  + 'px'
canvas.style.height = rect.height + 'px'
ctx.scale(ratio, ratio)                  // 之后直接用逻辑像素画
```

保证在 Retina/HiDPI 屏幕上不会发虚。

## 八、分析样式的其它可视化渲染

### 8.1 四关节发力条（bars-card）

```
┌────────────────────────────────────────────────────────┐
│ [Hip ] 髋  3.2/8.6   ████████░░  (当前值/峰值)
│ [Chest] 胸  4.1/10.2  █████████░  (上层亮=当前；下层暗=标准)
│ [Shldr]肩 7.5/11.3  ████████░░█  发金色/蓝/绿/红 渐变
│ [Elbow]肘 9.8/12.1  ██████████  + 渐变 + 扫光动画
└────────────────────────────────────────────────────────┘
```

- 下层阴影 bar（`bar-shadow`）= 标准动作在当前阶段的参考强度（高斯脉冲曲线，根据标准窗口中心计算。
- 上层亮条（`bar-fill`）= 用户当前值 / 该关节）。
- 每条条 `bar-sheen` 扫光动画。

### 8.2 标准参考强度脉冲曲线（getStandardCurrentValue）

```js
// 见 [getStandardCurrentValue](file:///c:/Users/hhyyz/Desktop/volleyball/tennis-lab/src/components/LocalPoseAnalysis.vue#L800-L811)
以 髋 peak 在标准窗口中心 center（center:
  distance = |progress − center|
  高斯衰减 = exp(−distance² / (2·width²))
  输出：peak · (baseLift + 0.92·pulse)
```

标准在 4 个关节在时间轴上形成 4 个顺序波峰 → 按 `hip(0.24) → chest(0.44) → shoulder(0.66) → elbow(0.84) 的中心，因此标准阴影条会随着 scrub 滚动呈现 4 峰依次隆起的形状。

### 8.3 阶段文本 + 反馈建议（反馈建议）

- phaseText（当前阶段大标题）
- phasePromptText（当前阶段讲解）
- feedbackPromptList（最多 4 条，来自 相位讲解 + 当前问题 + 与标准对比）

promptCodes 触发条件（例：
```
髋峰值 < 8 → hip-drive-weak（髋驱动弱）
胸部 progress − 髋progress > 0.2 → chest-transfer-late（胸部传导晚）
肩部 progress < 胸部 progress → shoulder-early（肩部抢拍）
肘部峰值 / 肩部峰值 > 1.35 → arm-dominant（手臂主导）
...
```

## 九、与标准模板对比逻辑

见 [poseStandards.json](file:///c:/Users/hhyyz/Desktop/volleyball/tennis-lab/src/mock/poseStandards.json) 与 [compareWithStandard](file:///c:/Users/hhyyz/Desktop/volleyball/tennis-lab/src/utils/poseAnalysis.js#L277-L300)：

```
标准模板结构：
  peakOrder: ['hip', 'chest', 'shoulder', 'elbow']  // 发力顺序
  velocityBands: { hip: [8, 16], chest: [...], ... }  // 速度区间参考
  maxHipChestGap: 0.2                              // 髋胸允许最大进度差

对比步骤：
  1) 取用户 peaks 的各 peak.progress 排序，得到实际顺序 order
  2) 与 expectedOrder 逐位置对比，统计匹配数 matchedOrderCount
  3) 逐项阈值检测（hip-drive-weak / shoulder-early / ...）→ promptCodes
```
